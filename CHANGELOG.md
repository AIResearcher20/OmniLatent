Versioning Policy

The project follows Semantic Versioning:

- MAJOR version: incompatible architectural or API changes.
- MINOR version: new features and capabilities.
- PATCH version: bug fixes, documentation updates, and minor improvements.

Example:

- "0.1.0" — Initial project structure.
- "0.2.0" — Data pipeline completed.
- "0.3.0" — Baseline models implemented.
- "1.0.0" — First stable public release.
