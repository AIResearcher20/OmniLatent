# Versioning Policy

OmniLatent follows **Semantic Versioning (SemVer)**.

### MAJOR

Breaking architectural or API changes.

Example:

```
2.0.0
```

---

### MINOR

New scientific functionality.

Examples:

- New representation learning models
- Additional biomedical modalities
- New evaluation pipelines

Example:

```
0.2.0
```

---

### PATCH

Backward-compatible improvements.

Examples:

- Bug fixes
- Documentation updates
- Performance improvements
- Refactoring

Example:

```
0.2.1
```
